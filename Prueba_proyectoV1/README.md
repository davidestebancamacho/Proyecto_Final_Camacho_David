# 🎬 CinePredict AI

Proyecto de Machine Learning enfocado en la predicción del éxito comercial de películas utilizando técnicas de clasificación supervisada.

## 📌 Objetivo

Analizar variables como presupuesto, popularidad, votos y género para predecir si una película será exitosa comercialmente.

## 🚀 Tecnologías utilizadas

- Python
- Pandass
- Scikit-learn
- SHAP
- Plotly
- Gradio

## 🤖 Modelos utilizadosss

- Logistic Regression
- Random Forest

## 📊 Técnicas aplicadas

- Pipeline de Scikit-learn
- ColumnTransformer
- Explainable AI con SHAP
- Visualizaciones interactivas

## ▶️ Cómo ejecutar

1. Instalar dependencias:

```bash
pip install -r requirements.txt
```

2. Ejecutar el notebook en Google Colab o Jupyter Notebook.
